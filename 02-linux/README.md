# Linux Learning Journey

## Introduction

Linux is an open-source operating system widely used in servers, networking, cloud infrastructure, software development and cybersecurity.

As part of my cybersecurity learning journey, I am developing my understanding of Linux, its command-line interface, filesystem structure, system administration and security-related operations.

I am using Linux Mint as my learning environment and documenting my progress through theoretical explanations and practical exercises.

## Learning Objectives

Understand the Linux operating system and command-line interface.

Navigate the Linux filesystem.

Understand and use essential Linux commands.

Manage files and directories.

Understand Linux file permissions and ownership.

Identify users, groups and running processes.

Explore basic networking commands.

Understand the relevance of Linux in cybersecurity.
